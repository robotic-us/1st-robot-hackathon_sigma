phorce studio
해커톤 참가자 매뉴얼

phorce studio는 로봇을 조종하는 리모컨이 아닙니다. 로봇이 움직이기 전에, 로봇에게 필요한 것들을 미리 심어 두는 프로그램입니다.

여기서 저장하는 모든 것은 여러분의 노트북이 아니라 로봇 안(pcm과 SD 카드)에 남습니다. 로봇 전원을 껐다 켜도 그대로 유지됩니다. 이것이 "사전 설정"입니다.

1이 프로그램은 무엇인가요?

한 문장으로: 로봇의 "미리 정해 두는 값"을 만드는 도구입니다.

로봇이 나중에 스스로 움직이려면, 그 전에 사람이 정해 줘야 하는 것들이 있습니다.

  • 이 로봇에는 어떤 관절(모터)이 몇 개 붙어 있는가?
  • 각 관절의 "0도" 기준(영점)은 어디인가?
  • 전원을 켜면 어떤 자세로 시작할 것인가?
  • 어떤 동작(모션)들을 알고 있어야 하는가?

phorce studio는 이 네 가지를 화면에서 정하고, 로봇에 저장하는 프로그램입니다. 특히 네 번째 — 로봇을 손으로 직접 움직여서 동작을 가르치는 "교시" — 가 이 앱의 핵심입니다.

studio를 끄고 노트북을 치워도, 저장한 설정과 동작은 로봇에 그대로 남아 있습니다. 나중에 로봇이 혼자 움직일 때 쓰는 것이 바로 지금 여러분이 저장하는 값입니다.

3studio와 pcm — 누가 무슨 일을 하나요?

역할이 뚜렷하게 나뉩니다. studio는 "보여주고 결정받기", pcm은 "실제로 하기".

STUDIO 가 하는 일
  • 로봇의 지금 상태를 사람이 읽을 수 있게 화면·그래프로 보여줍니다.
  • 이름·영점·자세 같은 사람의 결정을 입력받아 pcm에 저장을 요청합니다.
  • 가르친 동작을 저장하기 전에 화면에서 미리 재생해 보여줍니다.
  • 연결이 잠깐 끊기면 스스로 다시 연결합니다.
PCM 이 studio 연동으로 하는 일
  • 붙어 있는 phact(축)들을 찾아서 목록으로 알려줍니다.
  • 받은 설정을 자기 내부 메모리(FLASH)에 저장합니다 — 전원을 꺼도 유지.
  • 교시 중 관절 각도를 1초에 1,000번 기록해 studio로 보냅니다.
  • 완성된 동작을 SD 카드에 파일로 보관하고, 요청이 오면 재생합니다.
studio는 통역사, pcm은 실행자입니다. 버튼을 누르면 studio가 pcm에게 부탁하고, 실제 저장·기록·재생은 전부 로봇 안의 pcm이 합니다. 그래서 결과가 로봇에 남습니다.

4시작하기 — 연결 화면

프로그램을 켜면 가장 먼저 보이는 화면입니다.

  1. USB 케이블로 노트북과 로봇(pcm)을 연결합니다.
  2. 연결할 포트 목록에서 로봇의 포트를 고릅니다. 대부분 자동으로 잡혀 있습니다.
  3. 연결 버튼을 누릅니다.

연결되면 studio가 pcm에 저장된 설정을 자동으로 읽어 옵니다. 수십 초 걸릴 수 있습니다 — 화면 안내를 보며 기다려 주세요. 끝나면 ① 설정 화면이 열립니다.

버튼누르면 생기는 일
연결선택한 포트로 pcm과 대화를 시작합니다.
다시 검색포트 목록을 새로 찾습니다. 케이블을 방금 꽂았다면 이걸 누르세요.
데모 열기 · 합성 데이터로봇 없이 가짜 데이터로 화면과 흐름만 구경합니다. 아무것도 저장되지 않습니다.
로봇이 아직 없어도 데모 열기 · 합성 데이터로 전체 화면을 미리 연습할 수 있습니다.

5화면 구성 — 3개의 화면과 아래 상태 바

왼쪽 세로 메뉴에서 화면을 고릅니다. 번호가 곧 작업 순서입니다.

화면하는 일
① 설정축 구성·이름·영점을 pcm에 저장합니다. 가장 먼저 할 일.
② 교시손으로 움직인 동작을 SD 카드의 모션 파일로 만듭니다. 이 앱의 핵심.
③ 모니터실시간 값을 그래프로 보고, 움직임 세기(게인)를 조정합니다. 확인용.

화면 아래 상태 바 — 어느 화면에서든 항상 보입니다

지금 상태 네 가지(pcm · 서보 · 교시 · 재생)와, 급할 때 쓰는 버튼 두 개가 있습니다.

버튼누르면 생기는 일
재생 정지재생 중인 동작을 멈춥니다.
로봇 힘 끄기모든 관절의 힘(서보)을 끕니다. 로봇이 이상하게 움직이면 이 버튼입니다.

꼭 알아야 할 낱말: "서보" = 로봇의 힘

서보 켜짐
모터에 힘이 들어가 자세를 버팁니다. 손으로 밀어도 잘 안 움직입니다. 재생할 때 필요합니다.
서보 꺼짐
모터가 힘을 뺍니다. 손으로 자유롭게 움직일 수 있습니다. 가르칠 때(교시) 필요합니다.

그래서 순서는 언제나 — 힘을 빼고 가르치고, 힘을 켜고 재생한다 입니다.

6① 설정  로봇의 기본을 pcm에 저장

위에서부터 순서대로 6개의 카드가 있습니다. 저장 결과는 전부 pcm 내부 메모리에 남습니다 — 전원을 껐다 켜도 유지됩니다.

1. 이름 설정

이 로봇의 이름을 정합니다. 저장을 누르면 이름이 pcm에 저장되어, 다음에 누가 연결해도 같은 이름이 보입니다.

2. 구성 확인 · phact 이름

지금 로봇에 실제로 붙어 있는 축(관절) 목록이 보입니다.

버튼누르면 생기는 일
지금 붙은 축으로 저장"이 로봇은 이 관절들을 쓴다"를 확정해 pcm에 저장합니다. 이후 모든 화면이 이 목록을 기준으로 동작합니다.
구성 해제확정을 지웁니다. 축 개수를 바꿀 때(관절을 더 붙이거나 뺄 때) 사용합니다.
이름 저장각 관절에 사람이 읽기 쉬운 이름(예: "어깨", "팔꿈치")을 붙여 저장합니다. 그래프와 목록에 이 이름이 나옵니다.

3. 영점 설정 (핵심)

영점 = 각 관절의 "여기가 0도"라는 기준점입니다. 관절을 원하는 기준 자세로 만든 뒤 원점 설정을 누르면, 그 위치가 0도가 됩니다. 실패한 축이 있으면 실패한 축만 다시 시도로 그 축만 다시 하면 됩니다.

영점은 동작을 가르치기(녹화) 전에 반드시 먼저 잡으세요. 영점을 나중에 바꾸면, 이미 저장한 동작들의 기준이 어긋나서 로봇이 엉뚱한 자세로 움직입니다.

4. 부팅 자세 옵션 (핵심)

로봇 본체의 버튼 1(제어 시작)을 눌렀을 때, 로봇이 어떤 자세로 시작할지 미리 정합니다. 옵션을 고르고 저장합니다. 자세를 직접 정하는 옵션에서는 현재 자세 가져오기(지금 로봇의 자세를 그대로 입력칸에 복사)나 전부 0°를 쓸 수 있습니다.

5. 종료 자세 옵션

로봇을 끌 때, 힘을 빼기 전에 어떤 자세를 취할지 정합니다. 부팅 자세와 짝입니다.

6. 모션 오디오

동작 재생 시 효과음을 켜고 끕니다. 꺼도 오류·안전 안내음은 계속 나옵니다.

이 화면의 모든 저장은 노트북이 아니라 pcm에 저장됩니다. studio를 꺼도, 로봇 전원을 껐다 켜도, 로봇은 이 값들을 기억합니다. 나중에 로봇이 버튼 1로 혼자 시작할 때 쓰는 값이 바로 이것입니다.

7② 교시  손으로 가르치고, 로봇에 남기기

"교시"는 로봇을 손으로 움직여서 동작을 가르치는 일입니다. 화면이 5단계로 안내합니다. 각 단계 카드는 제목을 눌러 자유롭게 접고 펼 수 있습니다.

  1. 슬롯 선택 로봇 안 움직임

    SD 카드에는 동작을 담는 번호 붙은 칸(슬롯)들이 있습니다. 격자에서 어느 칸이 차 있고 비었는지 한눈에 보입니다. 동작을 담을 슬롯을 고르세요. (SD 카드는 대부분 자동 인식됩니다. 안 되면 찾기… / 새로고침.)

  2. 동작 녹화 사람이 움직임

    서보(힘)가 꺼진 상태에서 ● 녹화 시작을 누르고, 로봇을 손으로 천천히 움직이세요. 그동안 pcm이 관절 각도를 1초에 1,000번 기록합니다. 끝나면 ■ 종료.

  3. 가르친 움직임 확인 로봇 안 움직임

    방금 기록한 움직임이 그래프로 보입니다. ▶ 재생은 화면에서만 재생합니다 — 로봇은 움직이지 않으니 안심하세요. 마음에 들면 이 결과로 저장 준비.

  4. 모션 저장 로봇 안 움직임

    이름과 메모를 확인하고 저장 버튼을 누르면, 동작이 SD 카드에 파일로 저장됩니다. studio는 저장 후 파일을 다시 읽어 제대로 저장됐는지 검증까지 합니다. 메모만 고치고 싶으면 메모만 저장.

  5. 로봇 테스트 로봇이 실제로 움직임!

    서보 켜기로 힘을 넣은 뒤 로봇에서 재생을 누르면, 저장된 모션을 실제 로봇이 재생합니다. 멈추려면 로봇 정지. 끝나면 서보 끄기.

로봇이 실제로 움직이는 버튼은 ⑤ 단계의 로봇에서 재생 뿐입니다. 누르기 전에 로봇 주변에 사람과 물건이 없는지 확인하세요. 놀라면 화면 아래 재생 정지 또는 로봇 힘 끄기.
저장된 모션 파일은 로봇의 SD 카드에 있습니다. 노트북을 치워도 로봇은 그 동작을 알고 있고, 나중에 Jetson(두뇌)이 "3번 동작 실행"이라고 명령하면 pcm이 그 파일을 꺼내 재생합니다.

8③ 모니터  실시간 확인과 미세 조정

왼쪽은 그래프, 오른쪽은 실시간 값 목록입니다. 로봇이 지금 무엇을 하는지 눈으로 확인하는 화면입니다.

그래프 도구

버튼누르면 생기는 일
최근 10초그래프를 최근 10초 범위로 맞춥니다.
화면만 잠시 멈춤그래프 화면만 멈춥니다. 로봇과 기록은 계속 돌아갑니다.
보기 초기화확대·이동한 그래프를 처음 상태로 되돌립니다.
두 점 재기그래프 위 두 점을 골라 시간·각도 차이를 재줍니다.
고속 로그정밀 데이터를 파일로 기록합니다. 분석이 필요할 때만 쓰세요.

게인 조정 (위치 PID)

게인 = 로봇이 목표 자세를 얼마나 세게, 빠릿하게 따라갈지의 세기입니다.

버튼누르면 생기는 일
적용새 게인을 로봇에 임시로 넣어 바로 시험합니다. 전원을 끄면 사라집니다.
설정 저장마음에 든 게인을 phact 내부 메모리에 영구 저장합니다.
서보 끄기시험 중 움직임이 이상하면 즉시 힘을 끕니다.

즉, 여기서도 규칙은 같습니다 — 적용은 시험, 저장은 각인. 저장한 값이 로봇의 사전 설정이 됩니다.

9이런 일이 생기면 — 당황하지 마세요

이런 화면이 보이면이렇게 하세요
"응답이 잠깐 끊겼습니다 — 작업은 그대로입니다" 아무것도 안 해도 됩니다. studio가 몇 초 안에 스스로 다시 연결합니다. 저장하던 내용은 사라지지 않습니다.
저장/읽기 중 SD 카드 드라이브가 잠깐 사라졌다 나타남 정상입니다. SD 카드를 studio와 pcm이 번갈아 쓰기 때문입니다. 화면 안내가 끝날 때까지 기다리면 됩니다.
한참 기다려도 반응이 없음 USB 케이블을 확인하고, 연결 화면으로 돌아가 연결을 다시 누르세요.
버튼이 눌리지 않게 흐려져 있음 지금 단계에서 쓰면 안 되는 버튼입니다. 버튼 근처의 안내 문구가 이유를 알려줍니다. 순서대로 진행하면 열립니다.
"부팅 에러 복구" 안내가 보임 축 구성과 실제 관절 개수가 달라진 상태입니다. 화면 안내대로 ① 설정에서 축 구성만 다시 저장(또는 구성 해제) 후 로봇을 재부팅하세요.

딱 이것만 기억하세요

① 설정 → ② 교시 → ③ 모니터
  1. 순서대로. 영점(① 설정)을 먼저 잡고 나서 동작을 가르치세요(② 교시). 순서가 바뀌면 동작이 어긋납니다.
  2. 힘을 빼고 가르치고, 힘을 켜고 재생한다. 서보 꺼짐 = 손으로 교시, 서보 켜짐 = 로봇이 재생.
  3. 로봇이 실제로 움직이는 버튼은 [로봇에서 재생] 하나. 누르기 전에 주변 확인, 급하면 [로봇 힘 끄기].
