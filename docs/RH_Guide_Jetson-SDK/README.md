# 참가자 가이드 (해커톤 2026-08-04)

phorce 시스템을 처음 접하는 참가자를 위한 **온보딩 자료 5종**. 각 문서는
`.html`(화면용)과 `.pdf`(인쇄·배포용) 두 형태로 있다. 골든 이미지가 설치된
젯슨 기준으로 작성됐다.

| 순서 | 문서 | 성격 | 이럴 때 |
|---|---|---|---|
| 1 | [01-quickstart](01-quickstart.html) | **퀵 가이드** — 코드 0줄, 10분 온보딩 | 처음 받았을 때. 로봇을 한 번 움직여 보기 |
| 2 | [02-tutorial](02-tutorial.html) | **튜토리얼** — 파이썬/C++ 단계별 심화 | 내 코드로 "보고→판단→동작" 만들기 |
| 3 | [03-manual](03-manual.html) | **매뉴얼** — 운영 규칙·안전·용어 참조 | "규칙이 뭐였지, 이 용어가 뭐지" 찾을 때 |
| 4 | [04-api-reference](04-api-reference.html) | **API 레퍼런스** — 구성도 + 전 계층 시그니처·필드 사전 | "이 함수 인자가 정확히 뭐지, 이 필드가 무슨 뜻이지" |
| 5 | [05-system-image](05-system-image.html) | **시스템 이미지 안내** — 구성도 + 커널 패치·설치물 총람 | "이 시스템이 어떻게 구성돼 있지" (리눅스 사용자용) |

권장 순서: **1 → 2 → 3**. 급하면 1만 봐도 로봇을 움직일 수 있다.
4·5 는 사전이다 — 순서 없이 필요할 때 편다.

## 세 문서의 관계 (Diátaxis)

- **퀵 가이드**는 *처음 성공 경험*(learning by doing)에 집중 — 개념 최소, 손 먼저.
- **튜토리얼**은 *기능을 하나씩 쌓는 학습* — 피드백 읽기 → 판단 → 재생 → C++.
- **매뉴얼**은 *찾아보는 참조* — 명령/API/토픽/거절코드/용어를 사전처럼.

```bash
soffice --headless --convert-to pdf --outdir . 0*-*.html
```
