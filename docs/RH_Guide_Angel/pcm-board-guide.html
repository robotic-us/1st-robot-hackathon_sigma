pcm 보드 사용 가이드

pcm은 로봇 몸속의 중앙 관리자 보드입니다. 화면이 없는 대신 불빛(LED)과 소리로 말하고, 버튼으로 듣습니다. 이 문서 한 장이면 충분합니다.

13초 요약

켜기
전원을 연결하면 저절로 켜집니다. 버튼 필요 없음.
움직임 시작
기능 버튼 1을 1초 꾹.
끄기
기능 버튼 2를 1초 꾹 → 다 끝나면 전원 분리.
급할 때
E-stop 스위치를 확실하게 누르세요.
불빛
초록 = 만져도 됨 · 노랑 = 물러서기 · 빨강 = 문제.
"삑" 소리
"지금 그 조작은 안 돼요"라는 뜻. 고장 아님.

2불빛(Status LED) — 로봇의 신호등

한 가지 색 = 한 가지 뜻. 깜빡이지 않고 켜져만 있습니다.

색뜻여러분이 할 일
파랑 부팅·준비 중입니다. 기다리세요. (안내 방송이 나오면 그대로 따라 하세요)
초록 안전한 대기 상태(파킹)입니다. 힘이 빠져 있습니다. 로봇을 만져도 됩니다. studio 연결·설정·교시는 지금 하세요.
노랑 로봇이 움직일 수 있는 상태입니다 (힘이 들어갔거나 동작 재생 중). 물러서세요. 노랑이 유일한 "비켜라" 신호입니다.
흰색 끄는 중입니다. 다 꺼질 때까지 잠깐 기다리세요.
빨강 문제가 생겼습니다 (부팅 에러·E-stop 등). 원인은 불빛만으로는 알 수 없습니다 — 소리와 studio 화면을 확인하고, 기본 해결책은 전원을 껐다 켜기입니다.

3버튼 — 눌러서 생기는 일

버튼은 스치듯 누르면 안 먹습니다. 1초쯤 꾹 눌러야 합니다 (실수 방지용).

버튼언제 · 어떻게누르면 생기는 일
E-stop 스위치 위험할 때, 언제든. 확실하게 꾹 (살짝 스치면 안 걸릴 수 있음). 모터 전원이 즉시 끊기도록 설계돼 있습니다. 빨간불 + 경고음 반복. 한 번 걸리면 스위치를 되돌려도 풀리지 않습니다 — 전원을 껐다 켜야 다시 쓸 수 있습니다.
기능 버튼 1
"움직임 시작"		 초록불(파킹)일 때, 1초 꾹. 3초 경고 방송 후 힘이 들어가고, 미리 설정해 둔 부팅 자세로 움직입니다 (불빛 노랑). studio ① 설정의 "부팅 자세 옵션"이 바로 이때 쓰는 값입니다.
기능 버튼 2
"끄기"		 운전 중일 때, 1초 꾹. 안내 방송 → 동작 정지 → 종료 자세 → 흰불. 다 끝나면 전원을 분리하세요.
기능 버튼 3 · 4 — 평소에는 아무 기능이 없습니다. 눌러도 아무 일도 일어나지 않습니다.
전원 버튼 — 지금 버전에서는 눌러도 아무 일도 일어나지 않습니다. 켜기 = 전원 연결, 끄기 = 기능 버튼 2. 이 버튼이 아닙니다.
부팅 직후에 기능 버튼 1과 2를 동시에 누르고 있지 마세요. 공장 점검용 시험 모드로 빠져 버립니다 (LED·스피커 자가진단 화면). 이 모드는 나가는 길이 없어서 전원을 껐다 켜야 합니다. 만약 부팅이 이상하게 멈췄다면 이걸 의심하세요.
기능 버튼 1을 눌렀는데 "삑" 소리만 나고 안 움직이면, 둘 중 하나입니다: ① studio에서 축 구성을 아직 저장하지 않았다 → ① 설정에서 저장. ② PC가 SD 카드 드라이브를 잡고 있다 → 파일 탐색기에서 드라이브를 "안전하게 제거"한 뒤 다시 누르세요.

4켜기부터 끄기까지 — 한 사이클

  1. 전원 연결 파랑

    "전원 켜짐" 방송이 나오고 스스로 부팅합니다. 그냥 기다리세요.

  2. 안내 방송 따라 하기 파랑

    "관절을 살짝 움직여 주세요" 방송이 반복되면, 각 관절을 손으로 조금씩 움직여 주세요. 로봇이 자기 자세를 찾는 과정입니다. 끝나면 다음 단계로 넘어갑니다.

  3. 준비 완료(파킹) 초록

    "시스템 준비" 방송과 함께 초록불. 여기가 기본 상태입니다 — studio 연결, 설정 저장, 교시(가르치기)는 전부 이 상태에서 합니다.

  4. 움직임 시작 (필요할 때만) 노랑

    기능 버튼 1을 1초 꾹 → "로봇이 움직입니다" 3초 경고 → 힘이 들어가고 부팅 자세로 이동. 노랑 불이면 물러서세요.

  5. 끄기 흰색

    기능 버튼 2를 1초 꾹 → 안내 방송 → 정지·종료 자세 → 흰불. 그 다음 전원을 분리하세요.

5소리의 뜻

pcm은 화면이 없어서 소리로 말합니다. 세 종류만 구분하면 됩니다.

이런 소리가 나면이런 뜻입니다
짧은 "삑" 한 번 "지금 그 조작은 안 돼요." 고장이 아닙니다 — 위 3번 표의 팁을 확인하세요.
같은 안내 방송이 반복 로봇이 뭔가를 기다리는 중입니다. 방송 내용대로 해 주면 진행됩니다 (예: "관절을 살짝 움직여 주세요").
빨간불 + 에러 방송 반복 부팅 에러입니다. 방송이 원인을 말해 줍니다. 기본 해결책은 전원 재투입.

6곤란할 때 — 자주 있는 3가지

① 빨간불이 켜졌어요

가장 흔한 원인: 저장해 둔 관절 개수와 실제로 연결된 개수가 다를 때 (예: 6축으로 저장했는데 4축만 연결하고 켬). 해결 두 가지:

  • studio를 연결하면 복구 안내가 뜹니다 — ① 설정에서 축 구성만 다시 저장(또는 해제)하고 전원을 껐다 켜세요.
  • 복구 화면이 잘 안 되면 그냥 전원을 껐다 켜고, 관절 연결부터 다시 확인하세요.

② studio 연결과 SD 드라이브가 동시에 사라졌어요

알려진 문제이고 여러분 잘못이 아닙니다. USB 케이블을 뽑았다가 다시 꽂으면 돌아옵니다. (긴 동작을 저장하는 중에 가끔 일어납니다.)

③ 아무 반응이 없어요

전원(배터리) 연결을 확인하고 전원을 껐다 켜세요. 부팅 직후 기능 버튼 1+2를 같이 누르고 있었다면 시험 모드에 빠진 것입니다 — 역시 전원 재투입.

관절(phact)을 하나도 안 붙이고 pcm 보드만 켜도, 축 구성이 비어 있는 상태라면 정상 부팅됩니다. 로봇 없이 studio 연결·설정·SD 카드 연습을 할 수 있는 "벤치 모드"입니다.
SD 카드를 슬롯에서 물리적으로 빼는 것은 전원을 끈 뒤에만 하세요. 켜진 상태에서는 pcm이 카드를 쓰고 있을 수 있습니다.

딱 이것만 기억하세요

  • 초록에서 일하고, 노랑에서 물러서고, 빨강이면 전원 재투입.
  • 버튼 1 = 움직임 시작 · 버튼 2 = 끄기 · 나머지 버튼은 잊어도 됩니다.
  • 급하면 E-stop — 단, 한 번 누르면 전원을 껐다 켜야 다시 씁니다.
  • pcm에 저장된 설정·동작은 전원을 꺼도 남습니다 — studio에서 미리 심어 둔 "사전 설정"이 이 보드의 기억입니다.
